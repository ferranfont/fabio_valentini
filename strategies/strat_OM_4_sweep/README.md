# Strategy OM 4 Sweep - Bounce & Bins Trading Strategies

Advanced order flow strategies for NQ futures based on cumulative volume analysis and price action bounces.

## Overview

This directory contains two distinct trading strategies that analyze order flow patterns using cumulative volume resets (orange dots) from the mushroom sweep analysis:

1. **Bounce Strategy** (`strat_bounce.py`) - Trend-following entries after price bounces from reset levels
2. **Bins Strategy** (`strat_bins.py`) - Contrarian entries at volume reset moments

Both strategies use the same foundational data: **reset events** (orange dots) generated by the cumulative volume indicator in `strat_sweep/plot_resample_sweep.py`.

## Strategy 1: Bounce Strategy (Trend-Following)

### Concept

Waits for price to bounce away from reset levels, then enters when price returns to the reset level, following the bounce direction.

### Entry Logic

**Step 1: Reset Event (Orange Dot)**
- Cumulative volume indicator resets to zero
- Creates a reset event with `reset_timestamp` and `reset_price`
- Observation window: **3 minutes** (configurable via `EXTENDED_LINE_MINUTES`)

**Step 2: Bounce Detection**
- Monitor price movement from reset level
- **Bounce UP**: Price moves ≥ **5 points** above reset_price
- **Bounce DOWN**: Price moves ≥ **5 points** below reset_price
- `MIN_BOUNCE` = 5 points (configurable)

**Step 3: Cross-Back Entry**
- **After Bounce UP:**
  - ✅ Bounce confirmed (price went up 5+ points)
  - ⏳ Wait for price to pull back down
  - 🟢 **LONG** when price ≤ reset_price

- **After Bounce DOWN:**
  - ✅ Bounce confirmed (price went down 5+ points)
  - ⏳ Wait for price to rally up
  - 🔴 **SHORT** when price ≥ reset_price

### Visual Example

```
Price bounces UP from orange dot:

    25135 ─────┐
              │ (bounce up 5+ pts)
              │
    25130 ────●─────────────  ← Orange dot (reset_price)
              ↓
              └─ X  ← Entry LONG when price crosses back down to reset_price
```

### Parameters

**File:** `main_strat_bounce.py`

```python
# Strategy Parameters
TP_POINTS = 5              # Take Profit in points
SL_POINTS = 5              # Stop Loss in points
POINT_VALUE = 20.0         # Dollar value per point ($20 for NQ)
CONTRACTS = 1              # Number of contracts per trade
NUM_MAX_OPEN_CONTRACTS = 20  # Maximum simultaneous positions
BREAK_EVEN_POINTS = 10.0   # Move stop to breakeven after this gain

# Bounce Parameters
EXTENDED_LINE_MINUTES = 3  # Observation window duration
MIN_BOUNCE = 5             # Minimum bounce movement in points
```

### Exit Rules

- **Take Profit**: +5 points from entry
- **Stop Loss**: -5 points from entry
- **Break-Even**: Move stop to entry price after +10 points in profit

### Running the Strategy

**Complete Workflow (Recommended):**
```bash

```

## Strategy 2: Bins Strategy (Contrarian)

### Concept

Enters immediately at volume reset moments (orange dots), betting on mean reversion based on price position relative to SMA200.

### Entry Logic

**Entry Trigger:**
- Occurs at `reset_timestamp` when cumulative volume resets
- Entry price: `reset_price` (exact orange dot level)

**Direction Logic (Contrarian):**
- **price_tag = 'up'** (price > SMA200):
  - Price is above SMA → Expect reversal **DOWN**
  - 🔴 Enter **SHORT** at reset_price

- **price_tag = 'down'** (price < SMA200):
  - Price is below SMA → Expect reversal **UP**
  - 🟢 Enter **LONG** at reset_price

### Visual Example

```
Price above SMA200 when reset occurs:

    25135 ────●────  ← Orange dot (reset_price > SMA)
              ↓
         SHORT entry (contrarian: expect drop to SMA)

    25120 ─────────  ← SMA200
```

### Parameters

**File:** `main_strat_bins.py`

```python
# Strategy Parameters
TP_POINTS = 5              # Take Profit in points
SL_POINTS = 5              # Stop Loss in points
POINT_VALUE = 20.0         # Dollar value per point
CONTRACTS = 1              # Number of contracts per trade
NUM_MAX_OPEN_CONTRACTS = 20  # Maximum simultaneous positions
```

### Exit Rules

- **Take Profit**: +5 points from entry
- **Stop Loss**: -5 points from entry
- No break-even mechanism (pure TP/SL)

### Running the Strategy

**Complete Workflow:**
```bash
cd strategies/strat_OM_4_sweep
python main_strat_bins.py
```

**Individual Backtest:**
```bash
python strat_bins.py
```

## Comparison: Bounce vs Bins

| Feature | Bounce Strategy | Bins Strategy |
|---------|----------------|---------------|
| **Philosophy** | Trend-following | Contrarian (mean reversion) |
| **Entry Timing** | After bounce + cross-back | Immediate at reset |
| **Entry Price** | Current price when crosses reset | Exact reset_price |
| **Observation Window** | 3 minutes | Instant |
| **Direction Logic** | Follow bounce direction | Opposite of price_tag |
| **Complexity** | Higher (multi-step) | Lower (single trigger) |
| **Best For** | Strong trends | Range-bound markets |

## Important Notes

### CSV Format

**Always use European format:**
- Separator: `;` (semicolon)
- Decimal: `,` (comma)
- Reading: `pd.read_csv(path, sep=';', decimal=',')`
- Writing: `df.to_csv(path, sep=';', decimal=',')`

### Timestamps

- All timestamps are in Madrid time (CET/CEST)
- Format: `YYYY-MM-DD HH:MM:SS.microseconds`
- Tick data is millisecond-precision

### Reset Events

**Orange dots represent:**
- Cumulative volume reset moments (timeout after 15 seconds without big volume)
- `cumulative_volume_before_reset` ≥ 300 (minimum threshold)
- Each reset has a `price_tag` ('up' or 'down') based on SMA200 comparison

**Orange bands (horizontal lines):**
- Extend `EXTENDED_LINE_MINUTES` forward from each reset
- Represent the observation window for bounce detection
- Width: 20px, opacity: 0.3

## Performance Tips

### Bounce Strategy Optimization

**Increase MIN_BOUNCE:**
- Higher values (7-10 points) filter weak bounces
- Reduces trade frequency but improves quality

**Adjust Observation Window:**
- `EXTENDED_LINE_MINUTES = 5` for slower markets
- `EXTENDED_LINE_MINUTES = 1` for fast scalping

**TP/SL Ratio:**
- Default: 5/5 (1:1 ratio)
- Try: 6/4 (1.5:1) for better risk/reward

### Bins Strategy Optimization

**Filter by Cumulative Volume:**
- Use `cumulative_volume_before_reset` ≥ 500 for stronger signals
- Modify in `strat_bins.py` line 260

**SMA Period:**
- Change `SMA_PERIOD` in `plot_resample_sweep.py` (default: 200)
- Lower values (100-150) for faster trend detection

## Troubleshooting

### No trades generated

**Possible causes:**
1. No reset events in `db_mushroom_bins.csv`
   - Check `strat_sweep/plot_resample_sweep.py` output
   - Lower `MIN_CUMULATIVE_VOLUME` threshold

2. No bounces detected (Bounce strategy)
   - Lower `MIN_BOUNCE` parameter
   - Increase `EXTENDED_LINE_MINUTES`

3. Time window mismatch
   - Ensure T&S data covers same period as reset events

### Chart not opening

**Fix:**
- Manually open HTML files from `charts/` folder
- Check browser permissions for local file access

### Memory errors

**Solution:**
- Use smaller T&S data file (30-minute subset)
- Reduce `NUM_MAX_OPEN_CONTRACTS` limit
